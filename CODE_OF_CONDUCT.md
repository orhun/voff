# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We expect everyone participating in Voff project spaces to be respectful,
constructive, and considerate. Harassment, discrimination, personal attacks,
and other behavior that would be inappropriate in a professional setting are
not acceptable.

Project maintainers are responsible for clarifying and enforcing this Code of
Conduct. Report unacceptable behavior to [Orhun Parmaksız](mailto:orhunparmaksiz@gmail.com).

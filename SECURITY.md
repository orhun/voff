# Security Policy

## Supported versions

Security reports are accepted for the latest released version of Voff. Please
include the affected version or commit in your report.

## Reporting a vulnerability

Please report vulnerabilities through
[GitHub's private vulnerability reporting](https://github.com/voffsh/voff/security/advisories/new).
If private vulnerability reporting is unavailable, email
[Orhun Parmaksız](mailto:orhunparmaksiz@gmail.com). Do not report security
issues in public issues or pull requests.

Please include the affected component and version, steps to reproduce, and any
known impact. The maintainers will acknowledge the report and follow up as they
investigate it.

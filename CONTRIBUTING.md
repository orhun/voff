# Contributing

The binding contribution guide is maintained in [`promts/CONTRIBUTING.md`](promts/CONTRIBUTING.md).

All contributors must follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Report
security vulnerabilities through the private process in
[SECURITY.md](SECURITY.md), never through a public issue.

Unless you explicitly state otherwise, any contribution intentionally
submitted for inclusion in AgentMux is licensed under `MIT OR Apache-2.0`.

New model integrations must follow the provider boundary and shared contract
tests in [docs/PROVIDER_ADAPTERS.md](docs/PROVIDER_ADAPTERS.md).

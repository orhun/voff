How this calculator works and how to verify it

This page uses native number inputs and validates both values before calculation. Division is refused when the second value is zero. Results are announced to screen readers through a live status region.

  1. Enter 8 and 2; verify Add shows 8 + 2 = 10, Subtract shows 8 − 2 = 6, Multiply shows 8 × 2 = 16, and Divide shows 8 ÷ 2 = 4.
  2. Try dividing any number by 0; verify an inline error explains that division by zero is not allowed.
  3. Clear either field or enter an invalid value; verify the inline error requests two valid finite numbers.
  4. Use the keyboard: tab to fields and buttons, then use Enter, -, *, or / while a field is focused. Verify focus remains visible and all operations work without a mouse.
